    Rd

    Registration defaults

    Values filled in for you when you register a compound from an ELN entry — Origin is Synthesized for anything that came out of a reaction. Kept per vault, because a field that exists in one vault may not exist in the next. A form you open by hand from Explore Data is never touched, and a field that already has a value is never overwritten.

    Vaults appear here as you add them. The vault number is in the CDD address bar — /vaults/8158/. For a dropdown field the value must be one of its options spelled exactly, otherwise the field is left alone.

    ρ

    Remembered batch values

    Values you typed into stoichiometry rows (density, purity, concentration), remembered per molecule batch. A value saved on the batch or sample record itself always wins and removes the copy here.

    0 / 100 remembered

    Nothing remembered yet. Type a density, purity or concentration into a stoichiometry row whose batch has none — or pick a solvent for a solution row — and it will appear here.

    Ij

    HPLC injection

    The panel works out the injection volume for each reaction from the reaction molarity CDD prints on the solvent row: an aliquot of the mixture is diluted to the vial volume, and the injection is however much of that carries the target amount, rounded to the nearest 0.5 µL. The values below are starting points — a block can be recomputed for its own reaction (one drop or two) without changing these or any other reaction.
